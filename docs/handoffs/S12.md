## What exists now
- `core/voice/voice_adpcm.gd`: IMA ADPCM 4-bit codec. 16 kHz speech = ~65 kbit/s (raw 256, **-75%**), SNR ~35 dB.
  Packets are self-contained (predictor + step index in header) so unreliable loss never corrupts later packets.
- `core/voice/voice_fx.gd`: per-speaker effect buses `Voice_<peer>` (pitch-down, distortion, reverb), presets table.
- `core/voice_manager.gd`: ADPCM send (RAW PCM fallback via `use_compression=false` / `--voice-raw`; receivers decode
  every codec), silence suppression (240 ms hang), jitter buffer (60 ms pre-buffer, re-buffers after underrun,
  fade-in, 300 ms max queue), voice groups + rule table, kbit/s stats.
- **Loudness fix kept**: MIC_GAIN 12 (applied before 4-bit quantising), full 8 m / silent 45 m, `max_distance = 0`.
  A test asserts these values so they can't be reverted by accident.

## Public API (what other cards can use)
- `VoiceManager.set_speaker_effect(peer_id, preset, strength)`: presets `mage deep distort cave none`, strength 0..1.
- `VoiceManager.clear_speaker_effects()`, `set_voice_group(peer, group)`, `get_voice_group(peer)`,
  `set_voice_rule(speaker_group, listener_group, scale)`, `rule_scale(...)`, `voice_rules`/`DEFAULT_RULES`.
- Rules (`DEFAULT_RULES`): alive<->alive, alive<->dead proximity (GDD: same range); dead hear dead everywhere;
  scale 0 = muted, `RULE_GLOBAL` = full volume at any distance. Call `set_voice_group` for the LOCAL peer only
  (SpectatorManager already does); the group travels in each voice packet so everyone else learns it.
- `tx_kbps`, `rx_kbps`, `status_line()` (F3 overlay shows them).
