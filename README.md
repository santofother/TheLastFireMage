# The Last Fire Mage
6-player Godot party game: a small fire mage hunts tiny villagers through a seaside town while a firestorm closes in. Proximity voice chat is central.
Godot project: `the-last-fire-mage/`. Design: `docs/design/GDD.md`. Tests: `tools/run_tests.sh`.
How we build it with multiple agents: [docs/workflow/WORKFLOW.md](docs/workflow/WORKFLOW.md) (rules for agents: `AGENTS.md`).
